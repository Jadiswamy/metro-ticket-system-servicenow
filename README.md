# metro-ticket-system-servicenow
Metro Ticket Generating System using ServiceNow

📌 Project Overview  

This project automates metro ticket booking and fare calculation in ServiceNow using Catalog Items, Catalog Client Scripts, UI Policies, and Variables.  
The system allows users to book metro tickets, select journey type, calculate fare automatically, and choose payment methods digitally.

---

⚙️ Features  

- Metro ticket booking through Service Catalog  
- Automatic fare calculation based on passengers and journey type  
- Single and Return journey support  
- Dynamic field visibility using UI Policies  
- Payment mode selection  
- Automated form behavior using Catalog Client Scripts  

---

🛠️ Technologies Used  

- ServiceNow  
- Catalog Client Scripts  
- Catalog UI Policies  
- JavaScript  
- Service Catalog
